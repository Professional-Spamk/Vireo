# Vireo

## Starfall Showdown

A fast local two-player arcade duel starring the original anime-inspired rivals Nova and Vex. Race to collect the glowing coins before the 60-second round ends; the player with the higher score wins.

Open `index.html` in a browser to play, or serve this folder with `python -m http.server` and visit `http://localhost:8000`.

- **Nova:** move with `W` `A` `S` `D`; press `E` to dash.
- **Vex:** move with the arrow keys; press `Enter` to dash.
- On small screens, use the on-screen touch controls. Dashes have a short cooldown.
